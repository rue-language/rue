Methodology

Benchmarks run automatically against trunk on Linux x86-64, Linux ARM64, and macOS ARM64 runners. Each point represents a measured commit. When commits land faster than a run completes, an in-flight run may be cancelled in favor of the newest commit.

The primary charts use absolute time on one machine. Comparisons only cross points that the benchmark model marks comparable, and their classification accounts for observed variation. Normalized indexes are reserved for the cross-platform view because absolute timings from unlike machines should not be overlaid.
