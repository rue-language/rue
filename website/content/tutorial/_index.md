Welcome to the Rue tutorial. It teaches the language as it exists today, from
your first program to a small real one split across files and covered by tests.

Rue is an early-stage compiled language exploring memory safety without a
garbage collector and without lifetime annotations. It is not ready for real
projects yet. If you are curious about where it is headed, this tutorial shows
you what works now and is honest about what does not.

Every program in this tutorial is compiled, and most are also run, against the
current compiler as part of the project's test suite. If something here does not
work for you, that is a bug: please
[file it](https://github.com/rue-language/rue/issues).
