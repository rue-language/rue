# Benchmark Data

This directory contains benchmark history data for the Rue compiler performance dashboard.

## Files

- `history-<platform>/index.json` — atomic history index generated by CI.
- `history-<platform>/shards/YYYY/MM/<sha256>.json` — immutable benchmark runs.
- `history-<platform>.json` — optional legacy input used only during migration.

## Data Format

Version 3 uses a compact index whose `shards` array points to per-run files:

```json
{
  "version": 3,
  "format": "rue-benchmark-history",
  "platform": "x86-64-linux",
  "run_count": 1,
  "shards": [{"path": "shards/2026/07/<sha256>.json", "run_count": 1}]
}
```

## Updating History

History is updated automatically by CI on each commit to trunk. To run manually:

```bash
# From repository root
./bench.sh

# Or to just save results without updating history:
./bench.sh --no-history --output results.json
```

## Retention

History is logically unbounded. Runs are content-addressed, retained permanently,
and loaded through the atomic index snapshot.
