# Agent task contract

Use this for an issue implementation or risk-appropriate adversarial-review
handoff. Prefer the task conversation or a Linear comment for the full contract.
Keep a PR description tool-neutral and concise; the issue and PR remain the
durable record. `AGENTS.md` controls conflicts between instructions.

```text
BRIEF (sender/coordinator)

Objective (outcome):

Scope (outcome, subsystem, anticipated files):
Non-goals:

Authority:
- Linear issue:
- AGENTS.md:
- ADR/spec:
- Related PR or artifact:

Current source/tests proof (paths, call sites, tests):

Constraints:

Deliverable:

Verification:
- Focused check:
- Broader/formatting check:
- Evidence location:

Expected terminal condition:

RETURN (worker/implementation agent or reviewer)

- Changed files:
- Rationale:
- Ordinary in-scope fixes or assumptions noted:
- Results:
- Current source/tests proof confirmed or gaps:
- Known risks or blockers:
- Open questions:
```
