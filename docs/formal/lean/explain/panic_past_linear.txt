 panic_past_linear
════════════════════════════════════════════════════════════════════════════════
A @panic past a live linear binding whose type declares a destructor: §5.7
exempts the ⊥_panic edge from §5.6's obligation and §6.12 runs no drop, so the
value is consumed zero times with no violation and nothing prints before the
trap. The let's tail is ⊥, so the checker reads no scope exit; before RUE-2368
it refused. The compiler accepts it.

Rules exercised: (Panic) §5.8 · (Let) §5.3 · (D-Panic) §6.12 · 3.8:51
