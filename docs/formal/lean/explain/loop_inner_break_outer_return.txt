An outer loop whose only break belongs to an inner loop, and which leaves by
return: (Loop-Div) types it never, so the i64 body checks. The loop counts to
3 and returns it. Seeded by the definition mutants (RUE-2465): an Expr.breaks
that looked inside the nested loop typed the outer loop unit and refused the
program, and no seed or generated case noticed.

Rules exercised: (Loop-Div) §5.7 · (Loop-Break) §5.7 · (Break) §5.7 · (Return-Value) §5.7 · (D-Break) §6.10

── The program ─────────────────────────────────────────────────────────────────

fn f0() -> i64 {
    {
        let mut v0: i64 = 0;
        loop {
            {
                loop {
                    break
                };
                {
                    if { let t5a: i64 = v0; let t5b: i64 = 3; t5a >= t5b } {
                        return v0
                    } else {
                        ()
                    };
                    { v0 = (v0 + 1); }
                }
            }
        }
    }
}
