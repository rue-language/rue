 loop_move_every_path_breaks
════════════════════════════════════════════════════════════════════════════════
RUE-1615's shape: a loop whose body drops a linear binding and breaks. No path
reaches the back edge, so the loop-head state is the entry state and the move
is checked only against the exit, where the binding is MovedOut. The compiler
once reported "moved in a previous iteration" here. The destructor prints 1,
then the value 5.

Rules exercised: (Loop-Break) §5.7 · (Break) §5.7 · (@Drop) §5.3 · (D-Break) §6.10 · 3.8:79 · 3.8:80
