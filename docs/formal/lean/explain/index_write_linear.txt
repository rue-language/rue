 index_write_linear
════════════════════════════════════════════════════════════════════════════════
A dynamic-index write to an array whose element type carries a linear value: a
runtime index never establishes the element as MovedOut, so (Assign) §5.2's
3.8:77 premise reduces to not-carries-linear, which is false (the compiler:
E0493). The machine agrees on its own terms: the overwrite-drop would destroy
an unconsumed linear value, which is the linearOverwrite monitor. Seeded by
the definition mutation analysis (RUE-2486): mutant `index-write-linear`.
