 call_bottom
════════════════════════════════════════════════════════════════════════════════
A one-argument call whose sole argument diverges by return before the call is
reached, so the callee's activation record is never pushed and its body never
runs. Nothing follows the call, and there is no earlier argument for
RUE-2316's pending-temporary gap to strand. Seeded for RUE-2483: (Call-Bottom)
had no seed, no generated case, and no Explain row; Explain now names the call
this way when its argument list diverges, the way
(Loop-Div)/(Loop-Div-Backedge) are already told apart.

Rules exercised: (Call-Bottom) §5.3 · (Return-Value) §5.7 · (Dbg) §5.8

── The program ─────────────────────────────────────────────────────────────────

fn f0() -> i64 {
    {
        { let t2g: i64 = 1; @dbg(t2g) };
        f1(return 0)
    }
}

fn f1(v0: i64) -> i64 {
    v0
}



── What the checker says (§5) ──────────────────────────────────────────────────

Verdict: ACCEPTED by the checker (§5).
         Every function is well-formed by (Fn) §5.8 and the entry point takes
         no parameters, so `checkProgram_sound` ties the whole program to a
         real derivation and the §7 safety theorems apply to it.

         fn f0() -> i64  — body ⇒ i64, exit ⊥ (no normal exit)
         fn f1(v0: i64) -> i64  — body ⇒ i64, exit Σ [v0: i64 = Owned]

── Identities (§7) ─────────────────────────────────────────────────────────────
