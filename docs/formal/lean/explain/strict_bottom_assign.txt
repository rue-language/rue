An assignment's right-hand side diverges by return before the store: check
still demands the destination's own mut mark, which this one has, and the
let's body is the assignment itself, so no code follows it either. Seeded for
RUE-2483: no seed or generated case reached (Strict-Bottom) at any of its
positions.
