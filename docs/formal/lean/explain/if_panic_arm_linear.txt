 if_panic_arm_linear
════════════════════════════════════════════════════════════════════════════════
A @panic in one arm of an if whose other arm consumes a linear binding: the
panic arm is ⊥ and excluded, so the binding is MovedOut after the if and the
let owes nothing at its scope exit. The checker once gave the panic arm the
incoming Owned state, a linear join disagreement. The run takes the consuming
arm: the destructor prints 1, then the value 3.

Rules exercised: (If) §5.5 · (Panic) §5.8 · (Sub-Never) §5.7 · (@Drop) §5.3 · 3.8:51
