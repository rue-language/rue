 loop_div_backedge
════════════════════════════════════════════════════════════════════════════════
A break-less loop whose body completes normally at the type-level loop-head
state (an assignment), so it is never-typed by the back-edge case of
(Loop-Div)/(Loop-Div-Backedge) rather than the always-diverges case
loop_moved_prev_iteration already seeds. The counter starts one below
i64::MAX, so the second turn overflows and traps well inside the fuel bound
although the loop has no static exit. Seeded for RUE-2483: (Loop-Div-Backedge)
had no seed and no generated case.

Rules exercised: (Loop-Div-Backedge) §5.7 · (Assign) §5.2 · (D-Arith-Trap) §6.4

fn f0() -> i64 {
    {

        loop {
            { v0 = (v0 + 1); }
        }
    }
}
