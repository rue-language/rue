# Mosaic Handbook {#welcome}

Mosaic is a **deterministic** static-site generator written entirely in Rue.
It parses a project manifest, validates a cross-document graph, and renders
accessible HTML. Start with the [authoring guide](guide.html#getting-started).

## Why Mosaic

- one canonical build and check pipeline
- stable anchors and navigation
- escaped HTML, attributes, URLs, and JSON
- a deterministic [search index](reference.html#outputs)

> A site is only valid when every published page is reachable.

## Feature overview

| Area | Capability |
| --- | --- |
| Parsing | headings, lists, tables, code, links |
| Graph | pages, anchors, reachability |
| Output | HTML, CSS, XML, JSON |
